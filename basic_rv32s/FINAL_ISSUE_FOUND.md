# RT-Thread 移植问题 - 最终发现

## 🔴 **根本问题：CPU 陷入死循环**

### 现象

PC 在 `0xb8 → 0xbc → 0xc0 → 0xc4 → 0xc8 → 0xb8` 循环，永远无法推进。

### 查看代码（test_simple.elf）

```asm
b8:	00c12783    lw	a5,12(sp)
bc:	00178793    addi a5,a5,1
c0:	00f12623    sw	a5,12(sp)
c4:	00c12783    lw	a5,12(sp)
c8:	fef6d8e3    bge	a3,a5,b8 <main+0x34>
```

这是 `main` 函数中的循环：
```c
for (volatile int i = 0; i < 1000000; i++);
```

### 问题分析

**循环条件永远为真**：`bge a3, a5, 0xb8`
- a5 = 循环计数器 i
- a3 = 循环上限 1000000

如果 a3 的值是错误的（例如非常大或为负数），循环永远不会退出。

### 可能原因

1. **寄存器初始化错误**：a3 没有被正确设置为 1000000
2. **数据转发问题**：Hazard Unit 或 Forward Unit 有 bug
3. **编译器优化问题**：`volatile` 变量处理不当

### 建议

创建一个更简单的测试程序，直接输出字符，不使用循环。
